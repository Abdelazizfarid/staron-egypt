# Staron Egypt — website prototype

Astro static site (GSAP + Lenis motion). Content lives in `src/data/site.js` (shaped for a later CMS).

```bash
npm install
npm run dev      # http://localhost:4321/staron-egypt/
npm run build    # outputs dist/
```

Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
